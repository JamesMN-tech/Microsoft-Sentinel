# Learning Roadmap

These exercises are planned, not completed.

| Milestone | Completion evidence |
| --- | --- |
| Resolve Entra ID permissions | Passing prerequisites and authorized diagnostic configuration |
| Validate identity ingestion | SigninLogs and AuditLogs query results with timestamps |
| Validate threat intelligence receipt | ThreatIntelIndicators results and connector receipt telemetry |
| Investigate unsuccessful sign-ins | Documented query, result interpretation, and benign or suspicious disposition |
| Test one analytics rule | Rule configuration, required data, and controlled test outcome |
| Investigate one alert | Evidence, entities, timeline, and analyst reasoning |
| Test one playbook | Reviewed permissions and controlled execution history |

For each exercise, record what changed, why it was necessary, how it was tested, and what remains unresolved. Preserve the original lab results when adding new evidence.
